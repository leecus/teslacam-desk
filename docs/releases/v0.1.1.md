Windows x64 预览版，新增浅色/深色外观与中英文界面。

[下载 Windows x64 ZIP](https://github.com/leecus/teslacam-desk/releases/download/v0.1.1/TeslaCamDesk-v0.1.1-windows-x64.zip)

完整解压后运行 `TeslaCamManager.exe`，选择录像 U 盘，再点击“扫描建索引”。已包含 Qt、FFmpeg 和 MSVC 运行库。

## 本次更新

- 新增浅色与深色两套外观，标题栏右侧 ☀/☾ 切换。浅色以中性灰为主，深色使用暗色面板，两者共用同一套青色强调色。颜色统一由 `src/theme.cpp` 的调色板生成，不再散落在各处。
- 新增英文界面，“更多 → 语言”切换中文与 English。英文译文编译后内嵌在可执行文件中，发布包不需要额外的语言文件；缺少译文时回退为中文。
- 切换界面语言会保留当前设备、筛选条件、勾选和分页；有后台任务运行时禁止切换。
- 外观与语言都会写入本地设置，未设置时跟随系统配色与语言。
- 统一日历控件配色：去掉默认的红色周末、深色导航条与标准图标，星期表头不再与主体脱节。
- 事件元数据（触发原因、城市）参与搜索与预览定位，片段时长以实测值代替一分钟估算（自 0.1.0 之后的索引改进，旧索引可直接升级）。

## 说明

永久删除不经过回收站，无法撤销。首次使用建议先对录像副本操作。

验证环境：Windows 11 x64。已通过核心测试、ZIP 与逐文件哈希校验、x64 DLL 依赖检查，以及在含中文与空格的临时路径、隔离 PATH 环境下启动应用、创建索引并调用 FFmpeg 编解码。中文界面与上一版截图逐像素一致；英文界面在浅色与深色下均已核对。真实车型录像格式仍需更多样本验证；macOS 与 Linux 暂未提供发行包。

`TeslaCamDesk-v0.1.1-SHA256SUMS.txt` 提供安装包及第三方源码归档的校验值。第三方许可、模块 SBOM、构建配置和源码索引已随 ZIP 提供；同页的 Qt / FFmpeg `.tar.xz` 附件为对应源码归档。
