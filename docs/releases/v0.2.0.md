Windows x64 预览版，主打瘦身与免管理员安装。功能与 v0.1.1 一致，发布体积大幅减小。

本版本为本地打包验证记录，未在 GitHub 发布；正式交付见 [v0.2.1](v0.2.1.md)。

## 本次更新

- **新增可安装版本**：`TeslaCamDesk-v0.2.0-setup.exe`，双击安装。默认装到当前用户目录 `%LOCALAPPDATA%\TeslaCamDesk`，**不需要管理员权限**（公司受管电脑也可安装）。自动创建开始菜单快捷方式，可在“设置 → 应用”中卸载；卸载只删除程序文件，索引、缩略图和日志保留。安装器为中英文双语，跟随首次选择。
- **FFmpeg 命令行精简**：从 Gyan 的 9.0.2 essentials 全功能静态构建（101 MB）改为从源码精简编译的最小构建（约 5.4 MB），只保留程序实际使用的能力：H.264 解码、libx264 编码、mjpeg 缩略图、mov/mp4 与 concat 封装、scale/pad/setsar/fps 滤镜。缩略图、时长探测、裁剪导出、片段拼接四项功能与原版输出逐字节一致。
- **体积下降**：ZIP 从约 68 MB 降到 31.9 MB（约 -53%），安装包 22.2 MB。Qt、播放用 FFmpeg 动态库、MSVC 运行库仍在包内，功能不减。
- **许可合规**：精简版为 GPL-2.0-or-later（含静态链接的 libx264，同为 GPL-2.0-or-later）。`THIRD-PARTY-NOTICES.txt` 记录了完整构建配置，`third-party-sources.json` 给出 FFmpeg 9.0.2 与 x264 源码地址，GPL 文本随包提供。

## 说明

功能、界面与 v0.1.1 相同：浅色/深色主题、中英文双语、事件分组、四路预览、裁剪导出、收藏与清理。永久删除不经过回收站，无法撤销；首次使用建议先对录像副本操作。

验证环境：Windows 11 x64。已通过核心测试、ZIP 与逐文件哈希校验、x64 DLL 依赖检查、隔离环境下启动与建索引、FFmpeg 截帧与 H.264 编解码往返测试；安装器经静默安装/卸载实测，确认程序文件与快捷方式被清理、用户数据保留、卸载注册表项移除。真实车型录像格式仍需更多样本验证；macOS 与 Linux 暂未提供发行包。

`TeslaCamDesk-v0.2.0-SHA256SUMS.txt` 提供 ZIP 及第三方源码归档的校验值（setup.exe 的校验值见下方发布资产说明）。
